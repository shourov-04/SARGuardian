# AI Usage Disclosure

**Project:** SARGuardian — NASA Space Apps 2026, Dancing with the SARs

AI-assisted tools were used only for supporting communication and presentation media. They were not used to fabricate NISAR observations, scientific measurements, processing outputs or validation results.

## Tools and purposes

| Tool | How it was used |
|---|---|
| **Google AI Studio** | Assisted in preparing the voice-over used in the project demonstration video. |
| **Google Flow** | Generated short illustrative video clips used as supporting visual context in the presentation. |
| **CapCut** | Used for conventional post-production: assembling screen recordings and illustrative clips, synchronizing the voice-over, arranging transitions and finalizing the video export. |

## What is original project material

The SARGuardian website, user-interface recordings, processing screens, maps, NISAR-related result views and workflow demonstrations were captured from the actual project application and its processing environment. Google Flow clips are illustrative context and are not presented as satellite imagery, ground truth, NISAR data or proof of an event.

The scientific workflows use the project's code and actual NISAR data products. AI media tools were not used to generate GOFF/GUNW/GCOV measurements, compute displacement rates, create river-change candidate areas, alter processing manifests, or produce scientific validation metrics.

## Disclosure in the demonstration video

The video description and this document disclose the use of Google AI Studio, Google Flow and CapCut. This disclosure distinguishes AI-assisted presentation material from the real application recordings and scientific processing outputs.
