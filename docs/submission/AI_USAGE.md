# Use of Artificial Intelligence (AI)

AI-assisted tools supported SARGuardian across scientific engine design, software development, research, documentation, and presentation production. They acted as development and communication aids; project direction, engineering decisions, review, and responsibility for the resulting implementation remained with the team.

## Scientific Core Engine design and software development

- **Claude Code:** Supported architectural reasoning and design of the Scientific Core Engine, including exploring implementation approaches and refining processing workflows.
- **OpenAI Codex:** Assisted with implementation tasks, code analysis, debugging, and refinement across the repository.
- **GitHub Copilot:** Provided inline code suggestions and programming assistance to team members during software development.
- **ChatGPT (OpenAI):** Supported technical brainstorming, problem-solving, algorithm explanations, code-review assistance, documentation planning, and presentation drafting.
- **Google Gemini:** Supported research exploration, information synthesis, brainstorming, and refinement of project-related content.

AI-assisted code and technical suggestions were reviewed, adapted, and tested by the team before integration. The team remained responsible for deciding how scientific methods, product inputs, processing contracts, and user-facing interpretations were implemented.

## Presentation and media production

- **Google AI Studio:** Used to generate voice-over narration for the project presentation.
- **Google Flow:** Used to generate supplementary illustrative video clips for storytelling and visual communication.
- **CapCut:** Used for video editing and post-production, including combining application recordings, illustrative clips, voice-over, transitions, and final export. CapCut is listed as an editing tool; no separate AI-generation feature is claimed.

## Scientific responsibility and media distinction

AI tools were not used to fabricate NISAR acquisitions, GOFF offsets, GUNW phase/LOS observations, GCOV measurements, displacement values, processing manifests, or scientific validation metrics. Scientific outputs are produced by SARGuardian's implemented workflows from available source observations.

AI-generated video clips are illustrative presentation media. They are not satellite imagery, field photographs, or scientific evidence. The team is responsible for the scientific implementation, review, and interpretation of project outputs.
