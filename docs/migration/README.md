# Migration and source-lineage archive

This directory is a historical record of the work that consolidated SARGuardian's application, API, processing, and scientific source into the current public repository.

## What is preserved here

- Source repository and commit lineage.
- Import inventories and path maps.
- Dated migration and runtime checkpoints.
- Workflow and dispatch audits from the migration period.
- Database and deployment inventory snapshots.
- Source pins and historical validation records.

## How to use these records

These documents are valuable for provenance, change history, and reproducing the migration decisions made at the time each record was written. Their dates and referenced branches are part of the evidence. They are not the current project overview or a replacement for the current application and engine documentation.

For the current project, use:

- [Root project README](../../README.md)
- [Documentation index](../README.md)
- [Current architecture](../architecture/system-boundaries.md)
- [Reviewer guide](../submission/REVIEWER_GUIDE.md)

Do not rewrite or remove historical source records merely to make them look current. Add a new dated record when a new migration or source-lineage event needs to be documented.
